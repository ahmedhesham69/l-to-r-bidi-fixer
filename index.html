💻 الأكواد البرمجية (Code Blocks)

اكتب الأكواد بين 3 علامات تنصيص مائلة للحصول على نافذة برمجية بنمط macOS مع زر نسخ مباشر:

```bash
git add .
git commit -m "update files"
git push
```

⚡ قارئ الإنجليزي السريع والنطق الفوري

حل مشكلة بطء نطق الكلمات في المتصفحات التقليدية:

👆 نطق فوري بالنقر أو التحديد: انقر على أي كلمة أثناء القراءة أو حددها بالماوس ليتم نطقها في أقل من 20 جزء من الثانية بدون لاج.
🐢 النطق البطيء والترجمة: تظهر بطاقة تتيح لك سماع الكلمة ببطء 0.75x، أو معرفة المعنى وفتح قاموس Cambridge بنقرة واحدة.
